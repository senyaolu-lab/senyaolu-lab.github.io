01 /

转译之前，
先说清楚哪些关系要留下。

这是控制意图，而非控制成功的声明。三张图保留了同一场景的主要组织方式，局部对象与几何仍有可见漂移。

ANCHOR A / ARCHITECTURE

深青门面与中央入口

入口形成视觉通道，上方浅色篷布把画面分成连续的横向层次。

ANCHOR B / OBJECTS

左树、果箱、右侧自行车

两侧对象建立边界，前景水果给出色彩与尺度；检查有无增删或种类变化。

ANCHOR C / ATMOSPHERE

室内暖光与雨后反射

冷湿街道承接暖色灯光，保留营业中的亲近感；反射形状允许被媒介重写。

摄影基准同样是生成图像，不是未经处理的现场照片。这里的“摄影”指视觉语言。手作微缩指图像中的材质表达，未制作真实黏土模型。
02 /

把“感觉不对”，
变成可交流的观察。

五个维度分别评分，不合成总分。1 / 3 / 5 给出锚点，2 / 4 表示相邻锚点之间的判断。评分默认空白，由审阅者填写。

Five lenses.
One considered judgment.

先约定目标媒介，再评分。对摄影基准，“媒介表达”按摄影语言判断；对微缩版本，则按手作材料与体积语言判断。展开维度查看锚点。

这些是当前案例的操作化标注规则，尚未验证评分者间一致性，也不代表普遍美学尺度。

03 /

一次不够明显的转译，
以及下一轮的代价。

失败版本保留下来，让选择与修订可以被回看。v2 的媒介辨识更强，同时暴露了构图和对象细节的新问题。

v1 的问题：
变“柔和”了，却还不像手作。

第一版保留了真实摄影中的细密水果纹理、玻璃高光和湿地反射。画面虽有轻微模型感，但表面制作痕迹不足，难以与摄影基准拉开媒介差异。

  • 修改方向
    强化手工压痕、圆钝体积、分块地砖和缩尺景深，让材料与形态共同表达媒介。
  • v2 已观察到的变化
    篷布与墙面压痕更明显，门框边缘更厚，水果与木箱像被逐个制作。
  • v2 新出现的偏差
    果箱大小与水果位置改变；地面拼缝更粗，右侧浅绿水果更偏梨形。不能只因“更像微缩”就判定全部通过。
  • 下一轮的具体动作
    锁定果箱轮廓与门框边界，分区修改材质；对水果种类与位置另设检查项，再复核冷暖层级。
04 /

让审美探索，
留下可以复用的方法。

从参照到版本，再到标注与复盘，分别保存意图和观察。流程规格用于讨论与复用，不伪装成已执行的软件节点图。

01 / BRIEF

定义锚点

记录主体、布局、媒介目标与允许变化的部分；给参照文件固定 ID。

02 / VARIANT

单独保存版本

按媒介与版本编号保存，保留失败样本；不要覆盖不可复现的旧结果。

03 / ANNOTATE

先观察再判断

按五维锚点评分，注明具体区域与原因；区分事实、偏好与待验证推测。

04 / ITERATE

修一个主要问题

写下本轮改动与保留项，复查是否引入新的几何或语义偏差。

后续可扩展到更多构图与多个审阅者，在隐藏版本标签的条件下独立标注，再检查分歧。当前只有一个场景、少量版本与人工观察，适合展示分析过程，不足以得出模型能力排名或普遍美学结论。
