# 山海志 SHANHAI ZHI · 志怪茶饮品牌全案

> **喝下远古** —— 每杯茶，是一种远古异兽的化身

以《山海经》志怪异兽为核心的新中式茶饮品牌全案视觉设计。

🔗 **在线预览**：https://senyaolu-lab.github.io/shanhai-zhi/

---

## 项目背景

新中式茶饮赛道已极度拥挤，绝大多数品牌都在拼「国风插画 + 戏曲元素」，同质化严重。

「山海志」选择一条**没人走过的路**：以《山海经》志怪异兽为核心，每款茶对应一只异兽，形成可收藏的「异兽图鉴」体系。视觉语言是**东方暗黑奇幻**——玄墨、赤金、朱砂，与市面上所有茶饮品牌彻底区隔。

## 制作方式

品牌策略、视觉系统、专属杯型设计、字体排版体系均为原创设计；
画面视觉以 AIGC 生成，再由人工完成精修、统一调色与版式编排，实现风格高度一致的系列视觉。
