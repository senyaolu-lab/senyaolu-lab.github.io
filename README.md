## 项目列表

### PROJECT 01 · 山海志 SHANHAI ZHI — 新中式志怪茶饮品牌全案

以《山海经》志怪异兽为题材的原创茶饮品牌。每款茶对应一只异兽，构建可收藏的「异兽图鉴」体系；视觉语言为**东方暗黑奇幻**——玄墨、赤金、朱砂，与市面上所有新中式茶饮品牌彻底区隔。

含：品牌策略、视觉系统、专属杯型设计（杯身 + 杯盖）、五兽核心海报、产品视觉、世界观、包装与周边，共 16 张系列视觉。

📄 项目页：`shanhai.html`

### PROJECT 02 · 烦恼收容所 WORRY SHELTER — 治愈系毛绒潮玩 IP

不做"可爱动物"，而是把**负面情绪本身**拟人化——焦虑、拖延、社恐、emo、熬夜、选择困难，六只常规款 + 一只隐藏款，并以「收养」作为核心机制。视觉语言为**柔和治愈**，与项目 01 形成最大反差。

含：IP 定位、世界观、七只角色体系、角色图鉴、盲盒包装与周边。

📄 项目页：`worry.html`

### PROJECT 03 · 山海志 品牌动态演绎 — 品牌动态视觉识别

把项目 01 的静态视觉系统延展到**时间维度**。

- **Logo 动态演绎**：月山图腾的「生长」（金环画出 → 满月浮现 → 群山升起 → 字标浮现 → 朱砂落印），以 **SVG + CSS 实现**，网页内实时渲染，无需视频文件
- **AIGC 视频片段 ×5**：用已有品牌视觉做**图生视频**（即梦），把画面里本就含着的运动释放出来——巨龙盘绕、鲲破水而出、金雾升腾
- **品牌片头分镜**：15 秒 / 6 镜头
- **动效规范**：缓动、时长、转场、运镜四类规则

📄 项目页：`motion.html`

### PROJECT 04 · 心力价签 THE COST OF HEART — 洞察驱动广告战役

一次完整的广告战役推演（自主命题）。从真实消费观察提炼洞察：**年轻人不是没钱了，是没劲了**——省钱的本质不是钱包不足，而是心力不足。

核心创意：**给商品贴上第二种价签**，写上它消耗你多少心力。视觉语言为**冷感工业排印**——价格签黄、纯黑、纸白、警示红，瑞士硬网格、禁用圆角、条码图形，与项目 01 的暗金、项目 02 的柔和形成第三种气质。

含：命题与洞察、核心创意、价签视觉系统、主视觉 KV、6 张系列海报、3 种比例社交物料、地铁翻牌互动装置（可交互原型）、15 秒影片脚本、完整媒介排期。

📄 项目页：`ad.html`

**动态执行**：15 秒一镜到底影片，无音乐，只有一个声音——撕纸。画面里唯一的颜色是签黄；价签一张张落下，堆到第七张时镜头停住，**一只手的影子**移入压住价签一角，然后字幕浮现。

- **AIGC 成片**（两版实测）：`images/ad/film-15s.mp4`（V1，完成 A/B/C 三段）与 `images/ad/film-15s-v2.mp4`（V2，完成 A/B 两段，但 B 段撕口质量更佳）。两版都出现同一现象——**模型完成前 1–2 个动作后退回第一个场景并停住**（后 10 秒均为静止货架）。已确定结论：单次生成写多个场景必然退回首个场景兜底，故改为**单镜生成**，六条提示词见《心力价签-15秒单镜生成提示词》
- `film15.html` — **动态分镜（animatic）**：纯 SVG + CSS + JS，网页内实时渲染、可重播、可录屏导出。节奏、剪辑点与结尾字幕排版以此为基准；结尾 4 秒可直接录屏贴进成片
- 成片画面由 AIGC 生成，提示词见《心力价签-15秒AIGC连续提示词》；实拍方案见《心力价签-15秒影片拍摄脚本》

> **分工**：价签在画面里是完全空白的——不印任何字、数字、条码。AIGC 只负责卡纸质感与光线，所有文字由后期叠加，避免 AI 生成文字糊成乱码。

### PROJECT 05 · 息壤 XIRANG — 原创游戏企划与宣传物料

原创东方科幻造物养成企划。核心设定取自《山海经》「息壤」——**能自己生长的神土**：世界正被「寂」吞掉，先是声音，再是颜色；凡是发出的声音，都会在息壤里长出形状。一声叹息长出苔，一句哼唱长出藤，一次呼喊长出兽。

视觉语言为**冷生物光**——雾蓝、琉璃青、生金，一切光都从物体内部透出并带呼吸脉动，质感是青瓷开片、苔藓、菌丝、孢子、盐晶。

含：世界观、四步玩法循环（播种 / 聆听 / 嫁接 / 命名）、五大生长域、三名角色设定（各带视觉签名）、三只造物设定、主 Logo 与横版锁定、造物图鉴标本册版式、游戏内 UI 与预约页、首曝 KV 与卖点海报、45 秒 CG 预告片脚本、六周传播节奏。

📄 项目页：`game.html`

> 五个项目覆盖**五种能力**：商业品牌全案、角色 IP 设计、动态视觉、广告战役推演、游戏世界观与宣传；以及**四种完全不同的视觉语言**。
>
> 项目 01 与 05 同为东方题材，但一个画「神」（赤金玄墨、厚重渲染），一个画「活」（青蓝生物光、通透生长）——这恰好证明能按产品需求切换手法，而非只会一种东方。

## 制作方式

品牌策略、视觉系统、专属杯型与 IP 角色设定、字体排版体系均为原创设计；
画面视觉以 AIGC 生成，再由人工完成精修、统一调色与版式编排，实现系列视觉的高度一致。
