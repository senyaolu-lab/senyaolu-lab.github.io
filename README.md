### PROJECT 01 · 山海志 SHANHAI ZHI — 新中式志怪茶饮品牌全案

以《山海经》志怪异兽为题材的原创茶饮品牌。每款茶对应一只异兽，构建可收藏的「异兽图鉴」体系；视觉语言为**东方暗黑奇幻**——玄墨、赤金、朱砂，与市面上所有新中式茶饮品牌彻底区隔。

含：品牌策略、视觉系统、专属杯型设计（杯身 + 杯盖）、五兽核心海报、产品视觉、世界观、包装与周边，共 16 张系列视觉。

📄 项目页：`shanhai.html`

### PROJECT 02 · 烦恼收容所 WORRY SHELTER — 治愈系毛绒潮玩 IP

不做"可爱动物"，而是把**负面情绪本身**拟人化——焦虑、拖延、社恐、emo、熬夜、选择困难，六只常规款 + 一只隐藏款，并以「收养」作为核心机制。视觉语言为**柔和治愈**，与项目 01 形成最大反差。

含：IP 定位、世界观、七只角色体系、角色图鉴、盲盒包装与周边。

📄 项目页：`worry.html`

### PROJECT 03 · 山海志 品牌动态演绎 — 品牌动态视觉识别

把项目 01 的静态视觉系统延展到**时间维度**。

- **Logo 动态演绎**：月山图腾的「生长」（金环画出 → 满月浮现 → 群山升起 → 字标浮现 → 朱砂落印），以 **SVG + CSS 实现**，网页内实时渲染，无需视频文件
- **AIGC 视频片段 ×5**：用已有品牌视觉做**图生视频**（即梦），把画面里本就含着的运动释放出来——巨龙盘绕、鲲破水而出、金雾升腾
- **品牌片头分镜**：15 秒 / 6 镜头
- **动效规范**：缓动、时长、转场、运镜四类规则

📄 项目页：`motion.html`

### PROJECT 04 · 心力价签 THE COST OF HEART — 洞察驱动广告战役

一次完整的广告战役推演（自主命题）。从真实消费观察提炼洞察：**年轻人不是没钱了，是没劲了**——省钱的本质不是钱包不足，而是心力不足。

核心创意：**给商品贴上第二种价签**，写上它消耗你多少心力。视觉语言为**冷感工业排印**——价格签黄、纯黑、纸白、警示红，瑞士硬网格、禁用圆角、条码图形，与项目 01 的暗金、项目 02 的柔和形成第三种气质。

含：命题与洞察、核心创意、价签视觉系统、主视觉 KV、6 张系列海报、3 种比例社交物料、地铁翻牌互动装置（可交互原型）、15 秒影片脚本、完整媒介排期。

📄 项目页：`ad.html`

**动态执行**：`film15.html` — 15 秒品牌态度广告片（纯 SVG + CSS + JS 手写，网页内实时渲染、可无缝循环）。

情绪路径是**说中 → 累积 → 停住 → 被理解**：价签落入（说中）→ 撕裂线划开、心力栏推入（点破）→ 六张累加、计数器 0→6（累积）→ 8.9s 戛然而止、画面压暗推近（够了）→ 口号逐字浮现，朱红划线划掉「价格」，黄块压上「心力」（被理解）。

之所以用动态图形而非实拍：价签是廉价的、工业的、不高级的物件——**这个创意要的就是它不高级**。实拍会把它拍"美"，反而消解了创意的诚实。

> 四个项目覆盖**四种能力**：商业品牌全案、角色 IP 设计、动态视觉、广告战役推演；以及**三种完全不同的视觉语言**。

## 制作方式

品牌策略、视觉系统、专属杯型与 IP 角色设定、字体排版体系均为原创设计；
画面视觉以 AIGC 生成，再由人工完成精修、统一调色与版式编排，实现系列视觉的高度一致。
