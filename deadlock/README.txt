FILES AND USAGE
PNG files are digital exports. PDFs contain selectable text and can be used for print review.
Physical pieces are RGB proofs; confirm stock, trim, bleed and color conversion with the printer.
HTML design masters use native type/layout and reference images in ../assets. Keep the folder structure intact.
The compact creator-kit.zip contains PDF editions, two original artworks, source information and this readme. The complete archive contains individual PNGs, editable HTML, the local website and all supporting references.

Deadlock and its game artwork/characters belong to Valve. Reference assets retain their original attribution.
Original atmospheric illustrations are AI-assisted concept art, not gameplay screenshots.
